# BlizzardResearch

## Purpose

This repository contains verified research into the World of Warcraft Retail UI architecture and API behavior.

It supports addon development by separating:

- Blizzard API analysis
- Verified architectural research
- Addon migration studies
- Engineering experiments

## Repository structure

- `12.1.0/`
  - `Analysis/` — Verified Blizzard API and architecture documentation.
  - `BuffBars/` — Odysseus BuffBars migration studies.
  - `OUS/` — Odysseus Utility Suite migration studies.
  - `Experiments/` — Prototype notes and engineering experiments.
  - `Source/` — Original research notes and source material.
- `Samples/` — Standalone research samples that are not installed addons or production code.
